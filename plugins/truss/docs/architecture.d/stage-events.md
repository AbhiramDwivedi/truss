### Stage step times (ADR-0009)

`stage.js` has no clock, so it cannot stamp the time a step ended. Every crew result, passed or stopped, carries `stepEnds`, a list of `{ step, agent }` in the order the steps ended. The `agent` is the label of the last agent, member or runner, that returned while `crew.step` was that step (`workflows-src/stage/crew.js` `endStep`, read by `stepEndsOf` in `stopResult` and in the passed result of `qc` in `workflows-src/stage/qc.js`). A step that ran no agent has no entry. A step entered again, such as a QC fix round, moves its entry to the end, so each step has one entry. `finish` reads each agent's transcript time and writes the step's event with that time as its own `ts`, so a batch write at finish no longer gives every event the same time.
