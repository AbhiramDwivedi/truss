## Targeted tests (0.31.0)

- What: a green check runs the acceptance test with only its whole-suite step cut (`stripBlanketSuite` drops that `&&` segment or line and keeps the rest of the chain), then the tests the crew's diff reaches (`selectTests`), plus `targetedTests.map` entries for whole-repo checks and non-JS stacks (the repo's own map sends every doc root the citation lint scans, `CITATION_DOC_ROOTS`, to `doc-citations-031` and `release-026`). It runs the full suite instead when reach is unclear, and says why. Targeted runs take no heavy slot. After a QC PASS the stage runs `check --full` once, unless green already ran the full suite on that head. QC gets green's record and does not re-run a suite green on the same head. `plan-check` warns about an acceptance test that ends in `npm test`, and init proposes `targetedTests` for a non-JS stack.
- Reach: the selector follows the names a test uses, not whole files. An import goes through re-export barrels to the module that defines the name. A test that runs the factory CLI reaches only the handlers of the commands it names, read from the real command table. Only files the package.json test script's globs match are candidates. A namespace import used other than `ns.name`, a dynamic import and an unnamed command fall back to the whole file or every command. A one-line change to a `bin/factory/` module now selects 14 to 95 test files, down from 96 for every module. Since 0.32.0 a stage test can load one `workflows-src/stage/` module with `loadStageStep` and name it by a relative literal; a change to that module then selects it, and a change to another module does not (R-140, ADR-0050). A test that loads the bundle (`loadStageBundle`, or any literal naming `stage.js`) is still selected by every stage module. Only `stage-step-ruling.check.ts` is single-step so far, so a one-file change to a stage module selects 48 test files, and 49 for `ruling.js` (47 before 0.32.0).
- Entry points: `plugins/truss/bin/testmap.ts` (`selectTests`, `selectForCheckout`, `symbolGraph`, `suiteGlobs`, `stripBlanketSuite`, `stageBundles`), `plugins/truss/bin/build-stage.ts` (`loadStageStep`, `loadStageBundle`), `plugins/truss/bin/testmap-parse.ts` (`facts`), `plugins/truss/bin/factory/check.ts` (`checkTests`, `cmdCheck`), `plugins/truss/workflows/stage.js` (`noteTests`, `fullSuite`, `greenResultLines`), `plugins/truss/docs/truss-config.schema.json` (`targetedTests`); tests `plugins/truss/tests/testmap-031.check.ts`, `plugins/truss/tests/heavy-031.check.ts`, `plugins/truss/tests/stage-tests-031.check.ts`, `plugins/truss/tests/speed-031.check.ts`, `plugins/truss/tests/stage-steps-032.check.ts`, `plugins/truss/tests/stage-step-ruling.check.ts`.
- Owner: `truss-plugin-node` (testmap.ts, factory.ts), `truss-workflow-scripts` (stage.js).
